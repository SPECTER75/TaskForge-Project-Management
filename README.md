# TaskForge - Online Project Management Tool

## Overview
TaskForge is a Java-based collaborative workspace designed to streamline project execution, task assignments, and progress tracking. 

## Project Setup & Requirements
*   **Language:** Java (JDK 11+)
*   **Database:** MySQL 8.0+
*   **Libraries:** MySQL Connector/J (JDBC)
*   **Architecture:** MVC (Model-View-Controller) utilizing Object-Oriented Principles.

## How to Run the Project
1. Clone this repository to your local machine.
2. Execute the `database_schema.sql` script in your MySQL environment to construct the tables.
3. Update the credentials in `src/utils/DBConnection.java` to match your local database instance.
4. Compile and run the Java application from the `src` directory.
